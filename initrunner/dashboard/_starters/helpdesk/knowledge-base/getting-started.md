# Getting started with the helpdesk

Welcome. This sample article is bundled so the helpdesk starter works
before you add your own docs.

## How to use this agent

1. Ask a question about policies or how-to steps in this knowledge base.
2. Add your own Markdown files under `knowledge-base/` in your project
   directory. The next run indexes those instead of these samples.
3. For PDF or Word files, install the ingest extra (`uv pip install "initrunner[ingest]"`).

## Filing a ticket

If the knowledge base does not cover your issue, open a ticket with:

- A short subject
- What you already tried
- Any error text or screenshots
